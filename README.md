# Исходники генерации сайта Proxy Agency

Ветка `source` содержит скрипты, из которых собирается готовый сайт (ветка `main`). Netlify публикует только `main`.

- `gen/build*.py`, `gen/dc_*.py` — блоки для Tilda и доски дизайна.
- `gen/site/` — генератор сайта: `lib.py` (компоненты), `content_*.py` (тексты), `build_site.py` (сборка в `site/`).
- `tilda-*` — готовые блоки Tilda (входные данные для сайта), `logo-work` — логотипы, `structure.txt` — утверждённая структура.

В скриптах прописан абсолютный путь рабочей папки сеанса (переменная `ROOT`). При запуске в другом месте замените его на путь к папке с этими файлами. Сборка: `python3 gen/site/build_site.py` создаёт папки `site` и `site-preview`.
